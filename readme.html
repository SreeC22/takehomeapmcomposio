Live use

Open index.html for the library, or deploy this folder to Vercel. Search is one merged box: type an app name and press Get guide. Library guides open directly. Unfamiliar apps are researched live and generate a full guide, once. Live research uses the serverless endpoint in api/research.js, Tavily first when TAVILY_API_KEY is set in Vercel, with a 24 hour per instance cache and per instance rate limiting. No login and no secrets are needed to run it.

What is inside

  • index.html, style.css, app.js: searchable library, guide cards, guide detail view, quick guide view, live research, and shareable generated guides.
  • api/research.js: serverless live research endpoint. It searches for official developer and OAuth docs, fetches candidate pages in parallel, extracts registration, redirect, scope, endpoint, and review claims, and returns a full guide plus a research log and timings.
  • guides.json: full guide index, in the same schema used for human cards and agent JSON. It is minified, because a single upload argument cannot exceed about 128 KB.
  • guides/<id>.json: one machine readable guide per platform.
  • llms.txt: plain text index for agents and crawlers.
  • VERIFICATION-LOG.md: what was checked, what was corrected, and what could not be verified.
  • SUBMISSION-NOTES.md: paste-ready notes for the file upload submission.

Guides included

16 full guides, 0 summaries, checked against docs on 2026-10-31 as noted in each guide: GitHub, Slack, Google, Meta, Microsoft, Notion, Salesforce, HubSpot, Shopify, Zoom, Discord, LinkedIn, Airtable, Claude, ChatGPT, and Composio. Claude is an API key guide, not an OAuth flow. ChatGPT is Sign in with ChatGPT, commercial access is a limited trial. Composio is an auth config, not a provider OAuth app. No guide claims High confidence, and no guide claims a sign-in, app creation, or provider approval was completed.

Key decisions

  1. Same guide schema for every platform, so difficulty and time are comparable.
  2. Setup time is reported separately from approval wait time.
  3. Step by step guide, with a separate review timeline and a separate approval checklist.
  4. Human cards and agent JSON come from the same data.
  5. Live research returns a full guide with a research log, sources, timings, and confidence, not a static template and not a summary. Claims that cannot be verified from a fetched page are marked Unknown, not invented.
  6. Generated guides are shareable. Guide data is encoded in the share link and also saved in the browser, so a copied link survives refresh and sharing.
  7. Managed or custom is the first decision in every guide. Check Composio managed apps first, and go custom only for own branding, custom scopes, dedicated quota, faster polling, a custom instance, or enterprise branding.
  8. Quick guide view: steps show a short action, Who and Time chips, and a short Watch out line. Docs evidence is collapsed, and step URLs are cleaned of trailing punctuation before linking.
  9. Focused slice, not 100 thin guides. Sixteen full guides that can be checked beat a hundred guessed guides.

Live research, honest version

The merged search calls api/research.js. That endpoint searches for official developer and OAuth docs, fetches candidate pages in parallel, and extracts claims only where pages mention OAuth, client ID, redirect, or scopes. It returns a full guide, a research log with timestamps and failures, sources, timings, and confidence. Extraction is rule-based, not a language model, so quality varies by site, and failures are logged instead of hidden. A generated guide must be checked against official docs before use.

Style

Inter, matching Composio, uniform white background, pure blue #0000FF as the main accent.

Limitations

  • No account sign-in, app creation, or provider approval was completed for these guides.
  • Google and Meta timelines are ranges, not guarantees. Meta timeline was not confirmed from an official Meta page in this check.
  • ChatGPT commercial access is a limited trial, approval wait Unknown. Claude has no third party OAuth app in official docs checked. Composio itself has no approval, provider approval is separate.
  • Live research extraction is heuristic. It can miss JavaScript rendered official pages, and it can return Low confidence with Unknowns when no official page can be verified.
  • No credentials, tokens, or client secrets are included anywhere in this repo.

Verification
