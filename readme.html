Live use

Open index.html for the library, or deploy this folder to Vercel. Live research uses the serverless endpoint in api/research.js, which runs on Vercel with no paid API key. No login and no secrets are needed to run it.

What is inside

  • index.html, style.css, app.js: searchable library, guide cards, guide detail view, live research, and shareable generated guides.
  • api/research.js: serverless live research endpoint. It searches for official developer and OAuth docs, fetches candidate pages, extracts registration, scope, and review claims, and returns a guide plus a research log.
  • guides.json: full guide index, in the same schema used for human cards and agent JSON.
  • guides/<id>.json: one machine readable guide per platform.
  • llms.txt: plain text index for agents and crawlers.
  • VERIFICATION-LOG.md: what was checked, what was corrected, and what could not be verified.
  • SUBMISSION-NOTES.md: paste-ready notes for the file upload submission.

Guides included

Full guides, checked against docs on 2026-10-31 as noted in each guide: GitHub, Slack, Google, Meta, Airtable. Summary guides, not verified, that live research can expand: Microsoft, Notion, Salesforce, HubSpot, Shopify, Zoom, Discord, LinkedIn.

Key decisions

  1. Same guide schema for every platform, so difficulty and time are comparable.
  2. Setup time is reported separately from approval wait time.
  3. Step by step guide, with a separate review timeline card and a separate approval checklist card.
  4. Human cards and agent JSON come from the same data.
  5. Live research returns a guide with a research log, sources, and confidence, not a static template. Claims that cannot be verified from a fetched page are marked Unknown, not invented.
  6. Generated guides are shareable. Guide data is encoded in the share link and also saved in the browser, so a copied link survives refresh and sharing.
  7. Managed or custom is the first decision in every guide. Check Composio managed apps first, and go custom only for own branding, custom scopes, dedicated quota, faster polling, a custom instance, or enterprise branding.
  8. Focused slice, not 100 thin guides. Five full guides that can be checked beat twelve guessed guides.

Live research, honest version

The live form calls api/research.js. That endpoint searches for official developer and OAuth docs, fetches candidate pages, and extracts claims only where pages mention OAuth, client ID, redirect, or scopes. It returns a guide, a research log with timestamps and failures, sources, and confidence. Extraction is rule-based, not a language model, so quality varies by site, and failures are logged instead of hidden. A generated guide must be checked against official docs before use.

Limitations

  • No account sign-in, app creation, or provider approval was completed for these guides.
  • Google and Meta timelines are ranges, not guarantees. Meta timeline was not confirmed from an official Meta page in this check.
  • Summary guides are not verified against official docs in this build.
  • Live research extraction is heuristic. It can miss JavaScript rendered official pages, and it can return Low confidence with Unknowns when no official page can be verified.
  • No credentials, tokens, or client secrets are included anywhere in this repo.

Verification

See VERIFICATION-LOG.md for the sample checked, corrections made, and items that could not be verified. A sampled verification report is also on the home page.
