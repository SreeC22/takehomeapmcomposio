For agents

Same guide JSON for Claude Code, Codex, Cursor, Copilot, Gemini CLI, OpenClaw, OpenCode, Cline, and Grok Build. No plugin from this library to install.

Humans read the cards above. Agents can read the same guides as structured JSON, with no login.

  • /guides.json - full index of all guides
  • /guides/<id>.json - one guide, for example /guides/github.json
  • /llms.txt - a plain text index for agents and crawlers

Each guide JSON uses the same schema: id, name, difficulty, setupTime, approvalWait, steps, timeline, checklist, blockers, agentCan, humanMust, sources, tested, notVerified, confidence, and nextStep. The human cards and the JSON come from the same data, so they do not drift apart.
