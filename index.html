For agents: machine readable guides

Humans read the cards above. Agents can read the same guides as structured JSON, with no login.

  • /guides.json - full index of all guides
  • /guides/<id>.json - one guide, for example /guides/github.json
  • /llms.txt - a plain text index for agents and crawlers

Each guide JSON uses the same schema: id, name, difficulty, setupTime, approvalWait, steps, timeline, checklist, blockers, agentCan, humanMust, sources, tested, notVerified, confidence, and nextStep. The human cards and the JSON come from the same data, so they do not drift apart.

How to read a guide, and what to trust

Setup time is active work. Approval wait time is waiting for a provider. They are reported separately on purpose. A range means the provider does not publish one fixed number, or the time depends on your submission quality. Unknown means we could not confirm it from a source in this check, not that it is zero.

Full guides were checked against official or close to official docs on 2026-10-31, as noted in each guide. Summary guides are not verified and must be expanded by live generation and checked against official docs before use. No account sign-in, app creation, or provider approval was completed for these guides, and no secrets are included.
